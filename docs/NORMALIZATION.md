# Normalization verification

## Scope

Only Jieli-watch-research was normalized. Application source/documentation hashes still match the split manifest. No Git repository, remote or publication was created. No physical Bluetooth experiment or firmware/file transfer was performed.

## Language

Authored documentation, comments and runtime messages use English. Authored API identifiers were already English; no incompatible rename was required for language alone. OEM source labels, stable wire values, upstream proper names and unmodified English license notices are retained. The query reference is generated from English definitions. Non-English literal service text is displayed with Unicode escapes rather than substituted with a translated response.

The automated English check is a targeted heuristic, supplemented by manual review; it is not proof of natural-language classification for arbitrary future contributions. A temporary deliberately non-English fixture was rejected and removed. A synthetic address fixture was also rejected and removed.

## Attribution

The source register contains 21 entries separating comparisons, standards/vendor references, installed dependencies and unverified historical leads. Gadgetbridge file-level authors/revision and license headers were checked against retained private reference files; the current Codeberg refetch failed and is marked accordingly. Public repository/document pages and installed dependency notices were checked where available. Unknown licenses and unpinned sources are explicit. The legacy external-artifact URL/hash metadata are retained without their bodies.

No blanket assertion of fresh verification, permissive licensing or clean-room origin is made. No license for original work was chosen.
