# Publication scope

This folder contains an explicit selection of authored tooling and research documentation. The broad original analysis tree and private data were not copied. Bluetooth addresses and personal paths were removed from the notes; Windows tools require a target address through configuration.

APK files, reconstructed source, extracted libraries, disassemblies, third-party archives, private health/session captures, firmware and face binaries remain outside this folder. Historical notes may describe excluded evidence and record its filename. Such a reference does not include the underlying artifact or make the experiment reproducible from this folder alone.

## Source boundaries

- Own observations: identify the session, firmware and evidence level.
- Proprietary-client static analysis: state that origin explicitly; do not describe it as an open-source contribution or a clean-room implementation.
- External open-source projects: cite the project, credited authors, specific artifact or revision, and whether information was compared or code was reused.
- Dependencies: keep their existing notices and license terms unchanged.
- Publicly accessible material without a verified license: treat it as a cited reference, not permission to copy.

[Source register](docs/SOURCES.md), [machine-readable register](docs/sources.json) and [third-party notices](THIRD_PARTY_NOTICES.md) distinguish these roles. No upstream implementation source is identified as vendored in the authored tree. The parser and transport implementations were informed by proprietary-client analysis and local observations; they are not claimed to have been developed in isolation from all prior work.

## Before an actual release

No license for the original code or documentation has been selected. No ownership identity or license is invented by this preparation. Attribution is recorded separately from permission to reuse. Review any future copied material and run the content checks before publishing changes.
